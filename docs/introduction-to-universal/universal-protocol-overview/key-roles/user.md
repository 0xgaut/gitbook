# User

**User Benefits:**

* Seamless Cross-Chain Asset Transfers – Users can hold and trade assets across multiple chains without worrying about bridges or liquidity fragmentation.
* Access to Previously Unavailable Assets – Trade assets like DOGE, XRP, and others on DeFi platforms.
* Composability with DeFi Applications – Users can integrate uAssets into DEXs, lending platforms, and wallets.

**User Workflow:**

1. Users acquire uAssets via supported DEXs or directly from merchants.
2. Users transact, trade, and hold uAssets across supported networks.
3. If users wish to convert back to the original asset, they initiate a redemption request, which merchants fulfill by burning the token and releasing collateral.
