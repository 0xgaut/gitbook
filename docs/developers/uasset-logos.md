# uAsset Logos

Easily access official **uAsset token logos** by using the following URL format:

```
https://www.universal.xyz/wrapped-tokens/UA-TOKEN.svg
```

Simply replace **`TOKEN`** with the desired asset's symbol. For example:

* **Bitcoin (uBTC):** [https://www.universal.xyz/wrapped-tokens/UA-BTC.svg](https://www.universal.xyz/wrapped-tokens/UA-BTC.svg)
* **Ethereum (uETH):** https://www.universal.xyz/wrapped-tokens/UA-ETH.svg
* **Solana (uSOL):** https://www.universal.xyz/wrapped-tokens/UA-SOL.svg
