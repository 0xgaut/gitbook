## Key Features

### Deep Liquidity

Access off-chain order book liquidity for better pricing and lower slippage than traditional DEXs.

### Cross-Chain Trading

Trade assets from any blockchain on your preferred chain—no bridges required.

### Instant Execution

Trades are executed instantly using just-in-time liquidity from Universal's merchant network.

### Fully Onchain

All trades settle onchain. uAssets are composable ERC-20/SPL tokens you can use across DeFi.
