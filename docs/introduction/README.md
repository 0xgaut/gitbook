# Introduction to Universal

Universal is a wrapped asset protocol that enables trading of any token, on any chain. By leveraging 1:1-backed assets with verifiable reserves, Universal solves liquidity fragmentation and brings previously unavailable assets into DeFi.

## Overview

Universal provides developers and traders with access to 80+ cross-chain assets through a secure, transparent protocol built on the same architecture as leading stablecoins like USDC and USDT—but with key improvements.

## Key Features

### 1. Cross-Chain Asset Availability

Access assets from any blockchain on your preferred chain. Trade BTC, SOL, DOGE, XRP, and 80+ other assets without bridges or centralized exchanges.

### 2. 1:1 Backing with Verifiable Reserves

Every uAsset is fully backed by reserves held in regulated custody (Coinbase Prime). Verify reserves in real-time using [zkProof-powered verification](https://www.universal.xyz/reserves).

### 3. Just-in-Time Liquidity

Instead of pre-deposited liquidity pools, Universal uses dynamic minting. Merchants mint and fulfill orders on-demand, optimizing capital efficiency.

### 4. DeFi Composability

uAssets function as standard ERC-20 or SPL tokens, integrating seamlessly into DEXs, lending protocols, derivatives platforms, and wallets.

## What Problems Does Universal Solve?

### For Chains

New L1s and L2s launch without assets or liquidity. With Universal, popular crypto assets are available on day one, letting users trade immediately.

### For Token Issuers

Maintaining liquidity across multiple chains is expensive and inefficient. Universal lets users access tokens on any chain without issuers deploying capital everywhere.

### For Users

Users want seamless access to assets without managing bridges, fragmented liquidity, or multiple wallets. Universal provides a superior UX for cross-chain trading.
